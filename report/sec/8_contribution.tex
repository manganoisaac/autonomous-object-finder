\lead{Integration.} All work went through a shared GitHub repository. Changes entered the main line mostly through feature branches and pull requests (nine pull requests; \cref{fig:git}), and each merge was discussed in the team before it was taken up by the others. The modules meet at the small interfaces of \cref{tab:modules}, so perception, planning and safety could be developed in parallel. Every merged controller version was re-evaluated end to end with the same referee and benchmark (\cref{tab:mc}), which is how the integration defect of V0 and the slow scan of V2 were found. The team met weekly and discussed problems continuously in a Microsoft Teams chat.
